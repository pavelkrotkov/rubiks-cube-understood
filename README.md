# The Rubik's Cube, Understood

A free nine-lesson course that teaches you to solve the 3×3 Rubik's cube —
not by memorizing sequences, but by understanding why every algorithm works.

**[Start the course →](https://pavelkrotkov.github.io/rubiks-cube-understood/)**

## What makes this different

Most beginner guides hand you a list of move sequences to memorize. This
course builds the cube's underlying logic first — pieces, position,
orientation — and then introduces each algorithm as something with a
visible *reason*: a repetition cycle, a mirror image, a setup-and-undo
(conjugation), a do-undo interleaving (commutator), a conservation law.

By the end you can solve the cube from memory **and** explain, stage by
stage, why the method works — including why some cube states are
flat-out impossible.

## Structure

- `lessons/` — nine self-contained HTML lessons, in order
- `reference/` — a glossary and a printable algorithm cheat-sheet
- `assets/` — shared stylesheet and the quiz widget every lesson uses
- `index.html` — the course landing page

## Sources

The mathematical spine follows [Janet Chen, *Group Theory and the Rubik's
Cube*](https://people.math.harvard.edu/~jjchen/docs/Group%20Theory%20and%20the%20Rubik's%20Cube.pdf)
and [Tom Davis, *Group Theory via Rubik's
Cube*](https://www.geometer.org/rubik/group.pdf). The move sequences are
the standard beginner layer-by-layer method as documented by
[Ruwix](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/).
